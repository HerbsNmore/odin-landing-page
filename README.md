# odin-landing-page
My first landing page

Welcome to my first landing page. This is accumulation of all the knowledge I've acquired via TOP so far. 

I've learned how to make paragraphs, lists, and divs in HTML. I've learned how to make font colors, background colors, borders, and the wonderful world of flexbox. 

I'll be honest: learning flex was not easy and it still bewilders me a bit, but I'm excited to see how much further I can go (which will probably be a lot).

Enjoy!
